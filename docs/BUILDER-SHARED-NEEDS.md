# 遊戲／軟體清單與共同偏好

需求改為四個畫面：用途、加入遊戲／軟體、共同偏好、整台配置。已建檔且可對照的需求在第三步送出時，自動產生整台草稿；客人可直接核對需求，也能指定調整某類零件，無須逐頁選完八類。

## 名稱搜尋

`builder-apps.js` 為本機名稱索引，含遊戲／軟體類型、分類與搜尋別名。可切換類型、篩選分類、搜尋、加入或移除。最多 20 項，名稱最多 100 字；找不到可用搜尋框自行加入，Enter 加入不會跳到下一步。中文輸入組字中的 Enter 不處理。

這是有限的本機索引，不是 Steam、軟體商或網際網路的即時完整搜尋；收錄名稱不等於已有需求、實測或配置資料。現有可信需求仍來自 `data/builder-games.json`，本次沒有新增或虛構遊戲效能規格。

## 共同偏好與可信推薦

- 螢幕安排、解析度、型號、更新率、主機預算、外觀。
- 遊戲整體偏好：流暢優先、畫面與流暢兼顧、畫面優先、不確定。
- 是否同時執行、軟體工作量／版本／模組、進階 FPS／光追等自由輸入。
- 解析度不明不自行假設 1080P；明確解析度只匹配來源有標明同一解析度的目標，不把未標解析度的官方 FPS 表直接套用為 2K／4K。
- 整體偏好是意圖，並不是新的實測證據。目前不由「流暢優先」虛構 240 FPS，也不由「畫面優先」自動宣稱支援光追；推薦頁的可展開區顯示實際採用的條件與來源。
- 多遊戲保留各目標支持的 CPU／GPU 型號交集，容量、記憶體條數、標示速度、儲存與規劃電源下限分項取最大。沒有共同支持型號時交由 DK 確認，不以型號字串猜性能排序。
- 任一名稱缺乏對照、軟體工作量尚未驗證、同時執行或另有自由文字需求時，整體推薦轉為 DK 待確認，不只配符合其中一款的便宜主機。已選零件保留；不會清空或覆寫自填／自備項目。
- 目前可自動對照的遊戲目標仍以已建立的 VALORANT 1080P／1440P 參考規則為主；其他遊戲的官方需求可供閱讀，但現售型號完整對照尚待補齊。軟體的自動選配規則也尚未建置。

## 配置與草稿

整台配置頁顯示參考小計、待確認事項、八類零件、各類功能說明，以及採用需求、修改偏好、重新推薦與指定調整的入口。逐項頁可回到整台配置；3D、其他商品、自備、照片與正式 LINE 詢價流程沿用。

沒有現有零件時才自動產生推薦；已有選擇時先保留，重新推薦須確認。價格不因預算不足自動降低需求，小計仍是原價屋參考價，不是 DK 正式售價或供貨承諾。

沿用 `dk_builder_draft_v1`，新增 `experienceVersion:1` 與共同偏好欄位。舊名稱可辨識者正規化，舊版個別遊戲目標保存在 `legacyTargets` 並顯示於偏好頁／完整摘要供核對；不刪除既有零件、未完成自填草稿或照片。共同偏好及新增項目會存回本裝置，沒有伺服器寫入。

## 驗證

純邏輯／DOM：`NODE_PATH=/tmp/dk-builder-qa/node_modules node --test tests/builder-core.cjs tests/builder-experience.cjs tests/builder-ui.cjs`

真實瀏覽器：`DK_TEST_CHROME=/tmp/chromium node --test tests/builder-browser.cjs tests/builder-other-browser.cjs tests/builder-preview-browser.cjs`

涵蓋搜尋別名、分類與混合清單、去重、上限、文字安全、舊草稿、共用偏好、完整推薦、未知解析度／不支持的 4K 不假造配置、待確認解除後可推薦、分項合併、資料不足保留既有零件、直達核對、零件調整與返回、手機版、照片流程及 3D。

本次不包含全網資料串接、更多遊戲／軟體的效能實測建檔、DK 售價與即時供貨整合。此版先完成共同偏好與整台推薦的操作流程；之後擴充資料仍須逐項保留來源與驗證條件。
