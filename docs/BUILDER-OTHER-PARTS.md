# 配單「其他／找不到商品」

基線：正式 main `6a39c15`（PR #76）。本次在獨立功能分支實作，尚未合併／發布。

## 客人操作

八類零件頁面均有「其他／找不到想要的商品」。可填完整品牌型號、商品連結或附照片，至少一項，再選「希望 DK 代購」或「使用自己已有的零件」。按「套用到配單」後取代該類已選商品；下一個類別的自填內容獨立保存。

- 代購項目顯示待報價，不套用其他商品價格、不視為零元。小計明示仍有未計價項目，不是整台總價。
- 自備項目不計入採購小計，另提示規格、相容性與安裝／檢測費用待確認。
- 沒有規格資料的自填零件不會通過相容性認證；相關已知零件改標示待確認，仍保留其他已知衝突的檢查。
- 本版不會自動擷取任意商品網址、價格或規格，也不會自動把自填名稱模糊配成其他商品。
- 自動產生推薦時若已有自填／自備零件，保留現有配單並提示先確認規格，不覆寫客人的選擇。
- 換回清單商品時移除該項自填選擇，填寫草稿保留供再次編輯；「清除自填資料」會清除該欄草稿、選擇與照片。

## 草稿與照片

相容既有 `dk_builder_draft_v1`，增加 `others`（已套用）與 `otherDrafts`（尚在填寫）兩個欄位。舊版只含商品 ID 的草稿仍可恢復；本次未修改正式資料庫、庫存、訂單或後台。

照片支援 JPG、PNG、WebP，原始檔最多 10MB／四千萬像素。瀏覽器縮圖後轉成 JPEG，單張資料上限 120,000 字元；重新編碼不保留原始 EXIF。SVG、HEIC 與無法解碼的檔案會提示換格式，既有照片不被移除。每個類別最多一張照片。

**照片只暫存在客人的瀏覽器，沒有上傳到 DK 伺服器。** 配單摘要會註明附圖與檔名，提醒另傳官方 LINE；複製文字不會把照片或巨大的 data URL 塞入內容。清除瀏覽器資料會失去本機草稿。若儲存空間不足，保留記憶體內內容並顯示保存失敗，離頁時啟用未保存提醒。

圖片解碼完成後依原類別與請求序號保存，避免延遲完成後跑到其他類別，或在客人重設後重新加入舊照片。商品連結只接受 HTTP／HTTPS，拒絕附帳號密碼、javascript/data 等主動內容協定。自填文字均轉義；自填資料的價格、規格等未核可欄位不採用。
