# 配單 3D 組裝示意

目前提供可旋轉、縮放的通用直立機殼與八類零件示意，放在「你的配單」上方，可收合。這是 Canvas 即時投影的 3D 幾何，沒有外部模型、CDN、額外請求、WebGL 或新套件。

## 操作與選配連動

- 滑鼠或單指左右拖曳旋轉；手機保留垂直捲動。滑鼠亦可上下拖曳調整仰角。
- 圖片聚焦後支援方向鍵，＋／− 縮放，0 重設；也有對應操作按鈕。沒有自動旋轉或持續動畫。
- 選入、換選、移除零件、重設配單與草稿恢復時，更新模型與文字狀態；未選項目為灰色虛線。
- 清單商品依現有 `colorOf` 已辨識的黑／白色套用色調；未辨識顏色採通用配色。CPU、SSD 同樣是位置示意。
- 自填／自備零件使用琥珀色通用方塊，提示規格待確認。不從型號、照片或網址推論尺寸與款式。
- 若 Canvas 不可用，顯示替代文字，配單與金額仍可操作。繪圖只在選配、操作、展開或尺寸變更時執行，像素比上限 2。

## 模型邊界

不是特定 SKU 的實體模型。機殼、主板與零件形狀尺寸、安裝位置、風扇數量、鰭片、線材及燈效均不構成實際商品保證；未繪製線材。沒有真實機殼模型或逐型號資產。尚未建置水冷模型，現有可自動選配的清單散熱器仍依原有風冷規則；自填水冷以待確認方塊呈現。

示意圖不計算物理碰撞，也不取代 `builder-core.js` 的相容性規則，不會因模型畫得下就標為相容。原有規格缺漏、BIOS、扣具、接頭與供貨待確認提示保留。渲染不修改草稿內容、價格或商品資料。

## 局部驗證

實際 Chromium 測試：空配單、八類清單零件、其他商品的待確認狀態、恢復草稿、像素畫面隨旋轉／選配改變、按鈕與鍵盤、滑鼠及模擬觸控拖曳、縮放上下限、收合展開、1440／390 像素版面與 Canvas 不可用的降級。所有請求限制為本機 GET，檢查頁面錯誤與寫入為零。

同時執行既有 `tests/builder-ui.cjs`（18 項）及 `tests/builder-browser.cjs`、`tests/builder-other-browser.cjs`（3 項真實瀏覽器流程）確認受影響配單介面。
